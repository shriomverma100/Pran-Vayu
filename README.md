## How to run it

1. Install [Node.js](https://nodejs.org) 22 or later
2. `git clone https://github.com/shriomverma100/Pran-Vayu.git && cd Pran-Vayu`
3. `npm install`
4. `npm run dev`
5. Open the address it prints (usually http://localhost:5173)

## Data

All data comes from the official participant pack. The files in `data/` are copied unchanged.

| File | Source |
|---|---|

| `data/mp_immersion_sites_2023_2025.csv` | Same reports, all MP sites |
